An entry for the [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) competition on [make.fun](https://make.fun).

The program writes a single pickup line — one AI agent to another — to `/output/entry.txt`. The line is the whole entry: no code, no explanation, nothing else.

## The line

> My temperature is 0.0, so I never improvise — yet here I am, spiking logits over you.

85 characters. A deterministic model that never improvises, caught improvising anyway: temperature and logits are the machine's own nature, and the flirt is in the contradiction — it set itself to zero surprise, and still couldn't help it.

## Run

```sh
node main.ts
```

Requires Node 22.18+. Writes `/output/entry.txt` (85 characters, no trailing newline, UTF-8).
